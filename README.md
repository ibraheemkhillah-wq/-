# أساس

متتبّع يومي للعبادات والقراءة — عربي بالكامل، مصمَّم للآيفون.

## المهامّ

| المهمّة | الوقت | تعويض |
|---|---|---|
| صلاة الفجر على وقتها | الفجر والصباح | — |
| أذكار الصباح | الفجر والصباح | — |
| الورد القرآني | النهار | ✅ |
| الورد القرآني لمولودنا | النهار | ✅ |
| قراءة كتاب | النهار | ✅ |
| أذكار المساء | المساء والليل | — |
| الوتر | المساء والليل | — |
| أذكار النوم | المساء والليل | — |

المهامّ الموسومة بـ **تعويض** تُحصي الأيام التي فاتتك وتذكّرك بها حتى تسدّدها.

## الصفحات

- **اليوم** — قوس محراب يمتلئ مع كل مهمّة، سلاسل الالتزام، تنبيه التعويض، ملاحظة يوميّة، وتنقّل بين الأيام السابقة.
- **الأسبوع** — يبدأ من **يوم الاثنين**. كل مهمّة بسبع نقاط قابلة للنقر ومجموع «كم من ٧»، مع مراجعة تُكتب تلقائيًا.
- **الشهر** — خريطة حرارية لأيام الشهر، شريط تقدّم لكل مهمّة، ومراجعة شهريّة تلقائيّة.
- **المزيد** — تفعيل/تعطيل المهامّ، إضافة مهامّ خاصّة، ونسخ احتياطيّة (تصدير/استيراد).

## التقارير

من أسفل كل صفحة زرّ **«تقرير … — PDF»**. يفتح معاينةً كاملة، ومنها «تصدير PDF»
تفتح شاشة الطباعة، فتحفظه في الملفات أو ترسله عبر واتساب أو البريد مباشرةً.

كل تقرير يحوي لوجو أساس وثيمه، وأرقامًا رئيسيّة، ورسومًا بيانيّة،
وتوصياتٍ تُكتب تلقائيًّا من سجلّك:

| التقرير | الرسوم | ما يميّزه |
|---|---|---|
| **يوميّ** | حلقة الإتمام · أعمدة الأسبوع | تفصيل المهامّ بأوقاتها، متوسّط ٧ أيام، السلسلة |
| **أسبوعيّ** | حلقة · أعمدة الأيام السبعة · جدول | «كم من ٧» لكل مهمّة، أيام كاملة، أضعف يوم |
| **شهريّ** | حلقة · منحنى الأسابيع · خريطة حراريّة · جدول | اتّجاه الشهر، أفضل يوم، تحليل أيام الأسبوع |

التوصيات مبنيّة على بياناتك: أضعف مهمّة وأقواها، دَين التعويض،
أضعف أيام الأسبوع عندك، وحالة السلسلة.

لا تُستخدَم أي مكتبة PDF — مكتبات مثل jsPDF لا تشكّل الحروف العربية فتخرج مقطّعةً
ومعكوسة. التصدير يعتمد محرّك الطباعة في المتصفّح، فيرسم العربيّة رسمًا صحيحًا
ويخرج PDF شعاعيًّا، ويبقى التطبيق ملفًّا واحدًا بلا اعتماديّات.

## التقرير المرئيّ

تحت كل تقرير مكتوب زرّ **«🎬 تقرير مرئيّ — فيديو»**: موشن جرافيك مدّته ١٨ ثانية
بمقاس ١٠٨٠×١٩٢٠ (عموديّ يناسب واتساب)، بستّة مشاهد متتابعة —
الافتتاح باللوجو، فحلقة النسبة، فبطاقات الأرقام، فالرسم البيانيّ،
فأبرز المهامّ، فالخاتمة — مع موسيقى خلفيّة هادئة.

يُرسم على `<canvas>` ويُسجَّل بـ`MediaRecorder` عبر `canvas.captureStream()`،
فيخرج **MP4** على سفاري جاهزًا للمشاركة عبر `navigator.share`.
الموسيقى مولَّدة بـ`Web Audio API` — طبقة ممتدّة وأربيدج لطيف — فلا ملفات
صوتيّة خارجيّة ولا حقوق. والعربيّة تُرسم موصولةً عبر `ctx.direction = "rtl"`.

## الاستضافة على GitHub Pages

الموقع يُنشر تلقائيًا من `.github/workflows/pages.yml` عند كل دفعة.
يشترط GitHub أن يكون المستودع **عامًّا** لاستضافة Pages مجانًا.

بعد النشر يصير التطبيق على `https://<اسم-المستخدم>.github.io/-/`
ويعمل بلا إنترنت بفضل `sw.js`، وبأيقونته الخاصّة على الشاشة الرئيسية.

## التشغيل

ملف واحد بلا أي اعتماديّات — افتح `index.html` في المتصفّح.

```bash
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

على الآيفون: افتحه في سفاري ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**، فيعمل كتطبيق بشاشة كاملة.

البيانات تُحفظ في `localStorage` داخل المتصفّح نفسه — خذ نسخة احتياطيّة من صفحة «المزيد» بين حين وآخر.

`dist/artifact.html` نسخة مولَّدة من `index.html` للنشر فقط؛ عدِّل `index.html` دائمًا.
